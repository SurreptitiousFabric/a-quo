# Security policy

## Supported versions

A Quo has not made a stable release. Until it does, only the latest commit on
the default branch receives security fixes.

## Reporting a vulnerability

Do not open a public issue containing an exploit, private key, credential,
personal information, or recovery material. Use the repository host's private
security-advisory feature. A public contact route will be added before the
first hosted release.

## Security posture

Treat the project as experimental. Verification means that an artifact matches
a signed statement and that the corresponding signature is valid. It does not
mean the artifact is safe, reviewed, legal, current, or endorsed by A Quo.
